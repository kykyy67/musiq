# CascadeType и FetchType — настройка и обоснование

## CascadeType

| Связь | CascadeType | Обоснование |
|-------|-------------|-------------|
| **Artist → Album** (OneToMany) | `ALL` + `orphanRemoval = true` | Альбомы принадлежат исполнителю. Удаление исполнителя подразумевает удаление его альбомов. Удаление альбома из коллекции `artist.getAlbums().remove(album)` удаляет альбом из БД. |
| **Album → Track** (OneToMany) | `ALL` + `orphanRemoval = true` | Треки принадлежат альбому. Удаление альбома удаляет треки. Изменения коллекции треков (add/remove) синхронизируются с БД. |
| **Album → Genre** (ManyToMany) | без cascade | Жанры — самостоятельные сущности. Удаление альбома не должно удалять жанры. Связь только через таблицу `album_genres`. |
| **User → Track** (ManyToMany) | без cascade | Треки не принадлежат пользователю; связь только в `user_tracks`. Удаление пользователя не должно удалять треки. |

**Итог:** `CascadeType.ALL` и `orphanRemoval` используем только для связей «владеющая сторона — дочерние сущности» (Artist–Album, Album–Track). Для ManyToMany cascade на связанную сущность не ставим.

## FetchType

| Связь | FetchType | Обоснование |
|-------|-----------|-------------|
| **Album → Artist** (ManyToOne) | `LAZY` | При загрузке списка альбомов не тянем исполнителя. Иначе при маппинге в DTO для каждого альбома — отдельный запрос (N+1). Загрузка artist — через `@EntityGraph` / fetch join при необходимости. |
| **Album → Track** (OneToMany) | `LAZY` | Коллекции по умолчанию LAZY. Треки подгружаются только при обращении к `album.getTracks()`. |
| **Album → Genre** (ManyToMany) | `LAZY` | То же: загрузка по требованию; для списка альбомов с жанрами используем EntityGraph. |
| **Track → Album** (ManyToOne) | `LAZY` | При загрузке треков альбом не подгружается до вызова `track.getAlbum()`. |
| **Track → User** (ManyToMany) | `LAZY` | Список пользователей для трека подгружается только при обращении. |
| **Artist → Album** (OneToMany) | `LAZY` | При загрузке исполнителя не подгружаем все альбомы. |
| **Genre → Album** (ManyToMany) | `LAZY` | Обратная сторона; альбомы не подгружаются при загрузке жанра. |
| **User → Track** (ManyToMany) | `LAZY` | Треки пользователя подгружаются только при обращении. |

**Итог:** везде явно задан `LAZY`, чтобы не загружать связанные сущности без необходимости и избежать N+1. Где нужны связи в одном запросе — используем `@EntityGraph` или fetch join.
