================================================================================
ER-диаграмма: музыкальный каталог (Music Catalog)
================================================================================
Схема БД соответствует сущностям: Artist, Album, Track, Genre, User.
Связи: Artist 1──* Album, Album 1──* Track, Album *──* Genre, User *──* Track.
================================================================================

--- Код для Mermaid (вставить на https://mermaid.live или в Markdown с mermaid) ---

erDiagram
    artists ||--o{ albums : "has"
    albums ||--|{ tracks : "contains"
    albums }o--o{ genres : "album_genres"
    users }o--o{ tracks : "user_tracks"

    artists {
        bigint id PK
        varchar name "NOT NULL"
    }

    albums {
        bigint id PK
        varchar title "NOT NULL"
        int release_year
        bigint artist_id FK "nullable"
    }

    tracks {
        bigint id PK
        varchar title "NOT NULL"
        int duration_seconds
        bigint album_id FK "NOT NULL"
    }

    genres {
        bigint id PK
        varchar name "NOT NULL UNIQUE"
    }

    users {
        bigint id PK
        varchar name "NOT NULL"
    }

    album_genres {
        bigint album_id FK
        bigint genre_id FK
    }

    user_tracks {
        bigint user_id FK
        bigint track_id FK
    }

================================================================================
Описание связей
================================================================================
artists (1) ----< albums (N)     OneToMany: один исполнитель — много альбомов (artist_id в albums)
albums (1) ----< tracks (N)      OneToMany: один альбом — много треков (album_id в tracks)
albums (*) ---- album_genres ---- genres (*)   ManyToMany: альбом может быть в нескольких жанрах
users (*) ---- user_tracks ---- tracks (*)     ManyToMany: пользователь — много треков, трек — у многих пользователей
================================================================================
